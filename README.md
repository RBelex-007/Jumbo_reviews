# Tufts Jumbo Reviews

An open, student-built platform helping Tufts undergraduates—especially engineers—discover and evaluate HASS (Humanities, Arts, and Social Sciences) courses based on real workload, grading styles, and assessment mechanics.

## Quick Links
* **[PLAN.md](PLAN.md)**: Full master architecture, database schema, Tufts authentication strategy, and 5-phase implementation plan.

## Tech Stack
* **Framework**: Next.js 14+ (App Router) + TypeScript
* **Styling & UI**: Tailwind CSS + shadcn/ui + Lucide Icons
* **Database**: PostgreSQL (Supabase / Neon) + Prisma ORM
* **Authentication**: Auth.js / NextAuth (Tufts Google Workspace OAuth `@tufts.edu`)
* **Deployment**: Vercel
